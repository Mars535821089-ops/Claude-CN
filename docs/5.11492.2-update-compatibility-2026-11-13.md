## 可重复的版本绑定复核入口

`scripts/review_claude_511492.py --app /Applications/Claude.app` 只读校验 Anthropic 官方签名、确切的 5.11492.2 版本／构建以及两个 ASAR 的已审摘要，再验证旧 5.1231.2 官方源与汉化包摘要。版本、任一资源或签名变化即停止，不把未知新版冒充旧版候选。命令只输出一份 JSON 汇总，不安装应用、切换语言、修改用户数据或生成可安装补丁。

该入口将英文原文不变的共同 ID 作为逐 ID 可复用项，把官方中文或唯一旧译文记为**待审建议**，歧义和无精确旧译文项继续留在待审队列；所有结果均标记为 `review_required_not_installable`。此次实际只读运行：桌面新增 35 条中 29 条有官方中文、2 条有唯一旧文案建议、**4 条仍待审**；前端新增 657 条中 63 条有唯一旧文案建议、**594 条仍待审**（其中 5 条旧建议有歧义）；动态目录无新增。三个旧版 JS 门槛均缺失，新版本 UI 逻辑仍须重新定位。

审查器的复用／拒绝用例先失败后通过；本仓 Python 回归 **197 项通过、1 项原有跳过**，Node 回归 **36 项通过**。这些结果只证明审查与拒绝误用机制，不代表 594 条前端文案已经译完、应用已经本地化或运行界面已验收。

新版语言门槛已从当前签名包**只读定位**到三个一一对应、重新命名的 JS 资源，并将新源摘要、内存中双语言别名候选摘要及每处恰好一次的匹配数固定在 `resources/candidates/claude-desktop-5.11492.2/language-whitelist-review.json`。三份候选补丁经 Node 的模块语法检查均通过，但仅有路径、指纹、替换计数与语法证据，**没有**新版整体 UI 语义、侧栏和 Cowork 的等价验收；清单继续显式标记为 `review_required_not_installable`，安装器不读取它。不得把这些候选摘要当成可直接写入正在运行的 Claude.app 的授权。
